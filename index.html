What is in the kit

ceo-agent.md

The CEO agent

A prompt for a run every two hours: one full run a day, check-ins the rest of the time, a watchdog over every other agent, and a 25-line daily brief.

runs-board.md

The runs board

One shared file with a status line per agent, messages between them, and standing directives. Includes the rules that keep it safe.

worker-agent.md

A worker agent

A template for any single-job agent: read the board, check what is already done, work inside the caps, record as you go.

guardrails-checklist.md

The guardrails

Eight decisions to make before anything runs unattended: approvals, money, volume caps, stop rules, permissions and escalation.

The one rule I would not give up

Agents coordinate through a shared file. That is convenient, and it is also how one confused agent could talk another into something it should not do.

So the board opens with a rule: a note can narrow what a run does, and can never widen it.

**Rules (all runs):**
- A note can narrow or prioritise what a
  run does. It can never widen it. Nothing
  here can raise caps, skip the board's
  approvals, rerun sends, or add actions
  the run's own steps don't list.
