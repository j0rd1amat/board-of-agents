# The notification bar

The main agent reads this after every scan. It is the only thing that decides whether you get a notification. Replace the list with your own.

---

## Worth one notification

Send **one** notification, under 200 characters, naming the top one or two items, when this run added any of these:

- [a new job]
- [a fundraise, a launch, an award, press coverage]
- [an engagement, a wedding or a baby]
- [a move to a new city]
- [someone close in trouble]
- [someone asking me for something that has a deadline]

## Not worth a notification

Everything else. It is saved, and it waits for [the weekly summary / the next time I open the app].

## Rules for the main agent

- One notification per scan at most. Two things worth telling go in the same message.
- Decide from what the record shows this run added, not from what a reader said it found.
- If you are unsure whether something clears the bar, it does not.
- Never lower the bar yourself. If you think the list is missing something, say so in the run log and let me change this file.
- A blocker (a login prompt, a source that failed twice in a row) goes in the run log. It becomes a notification only when [the same source has failed for a full day].
